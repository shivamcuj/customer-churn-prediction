
# Customer Churn Prediction & Analytics

## Overview
An end-to-end data science project that analyzes
customer churn and predicts churn risk using
machine learning.

## Business Problem
Understand customer churn patterns and identify
customers who may be at risk of leaving.

## Tech Stack
Python, Pandas, NumPy, SQL, Scikit-learn,
Matplotlib, Seaborn, Streamlit.

## Workflow
1. Data cleaning and preprocessing
2. Exploratory data analysis
3. SQL-based business analysis
4. Model training and comparison
5. Model evaluation
6. Interactive prediction dashboard

## Models
- Logistic Regression
- Random Forest

## Evaluation
Report test-set precision, recall, F1-score,
ROC-AUC, and confusion matrix.

## Run Locally
pip install -r requirements.txt
python train.py
streamlit run app.py

## Links
Live Demo: https://customer-churn-prediction-srk.streamlit.app

## Limitations
The dataset is a sample customer snapshot.
Predictions are estimates, not guarantees.
